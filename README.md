# Java Practice

> [!NOTE]
> We are currently working on refactoring the repository and improving the practice so that it aligns for school use and personal home use. We're changing from just being a repository of practice problems to an actual hub for letting you practice.

Java Practice was built as a way to practice Java with varying difficulties in order to expand your knowledge of the language. We try to make the practice problems as realistic as possible.

## All Practices

| Name | Problem | Difficulty |
| :--- | :---: | ---: |
| [Get Sandwich](Easy/GetSandwich/) | Get the string surrounded by "bread" | Easy |
| [Grade Analyzer](Easy/GradeAnalyzer/) | Analyze test scores for a class | Easy |
| [Random Number Analyzer](Easy/RandomNumberAnalyzer/) | Generate 10 random integers in an array from 1 to 100 | Easy |
| [Username Validator](Medium/UsernameValidator/) | Check if a username is valid based on requirements | Medium |
| [Simple Command Parser](Hard/SimpleCommandParser/) | Simple CLI command line parsing tool | Hard |
| [Tic-Tac-Toe Board Checker](Hard/TicTacToeBoardChecker/) | Check a tic-tac-toe board to see who won | Hard |


## Contribution

Contributions are welcome! You can contribute by submitting new practice problems, improving existing problems, or fixing errors. Simply open an issue if you find a problem with current problems, or open a PR to add new things.
