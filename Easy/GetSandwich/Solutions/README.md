## Adding your solutions
- Create a pull request to the repository that adds your solution
- Create a folder inside of the `Solutions` folder with your GitHub username
- Copy and paste the .java file into the folder you just created
  - Can either be named `Solution.java` or the name of the practice
- Update this `README.md` file:
  - Update the table above this section with the correct information
  - `| Example | [Solution](example/solution.java) | [exampleauthor](https://github.com/example)`
  - Update the Solution Author to your name or GitHub username
  - Update the hyperlink inside `[Solution]` with the correct folder and file name
  - Update your GitHub link and username

Notes:
- Foul usernames and NSFW/non-school appropriate username solution requests will be rejected.
- Comments are appreciated, especially if they help out.
